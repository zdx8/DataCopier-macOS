FAQ

常见问题

和直接拖拽复制有什么区别？

DataCopier 逐文件记录处理结果并校验哈希，任何静默损坏都会被报告捕获；中断只留可识别的临时文件，不会出现残缺文件；完成后自动生成统计报告，适合素材交付、项目迁移等对数据完整性有要求的场景。

视频转码需要额外安装什么？

需要系统安装 FFmpeg（应用不内置、不分发）。可用 brew install ffmpeg 安装，应用会自动在常见路径查找，也可在「设置 → 运行环境」手动指定。不安装 FFmpeg 时拷贝与归档功能完全不受影响。

插入相机卡后没有自动弹窗？

请检查「设置 → 通用 → 检测 USB 移动设备」开关是否开启。开启后插入相机存储卡、U 盘等可移除卷会自动唤起新建任务并预填来源与设备型号。

支持哪些照片 / 视频格式？

照片支持 65 种扩展名（JPG、HEIC、RAW 系列等），视频支持 46 种（MP4、MOV、BRAW 等）。拍摄时间优先读取 EXIF 与视频容器，无法读取时按文件名时间戳、修改时间逐级回退。

如何自行构建？

项目使用 SwiftPM 手工打包，无需 Xcode 工程文件：./Scripts/run_selfcheck.sh 运行自检，./Scripts/build_app.sh release 打包应用，在仅有 Command Line Tools 的机器上即可构建。

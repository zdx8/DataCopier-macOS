# DataCopier 产品介绍视频脚本

面向：官网首页 / B站 / 小红书 / 朋友圈 等平台产品介绍。
基调：专业、克制、有信任感；不浮夸，强调「数据安全」与「省心」。
主色：绿色（与应用图标一致）。建议 BGM：轻快科技感，无歌词。

## 拍摄 / 制作提示

- **录屏**：窗口用浅色外观录制，干净背景；关键操作（插卡弹窗、哈希滚动、报告生成）放慢 0.5–1 倍速并加高亮圈。
- **转场**：用 0.3s 溶解，避免花哨转场破坏专业感。
- **字幕**：白底黑字或绿色描边，字号 ≥ 画面高度的 1/12，留出安全边距。
- **收尾卡**：可叠加 GitHub 仓库地址二维码（https://github.com/zdx8/DataCopier-macOS）。
- **配音**：男声/女声中音，语速偏慢、重音落在「校验」「归档」「报告」三个词上。
- **合规**：视频中若展示 ffmpeg 转码，需保留 FFmpeg 开源说明字样（本项目不分发 FFmpeg 二进制）。
